========================================
  央视频账号分析工具 (YSP Analyzer)
  用户使用说明 v2.0
========================================

【简介】
本工具用于采集央视频（yspapp.cn）高校账号的公开数据，无需登录。
支持批量采集、数据快照、交互图表、快照对比和全高校爆款监测。界面默认浅色，
左下角可切换深色；侧栏和内容区会同步切换，数据仍保存在本地 SQLite 数据库中。

【运行环境】
- Windows 10/11 64 位
- macOS 代码层已兼容，正式安装包仍待真实 Mac 验证
- 源码运行需要 Python 3.10+ 与 requirements.txt 中的依赖

【启动方法】
源码版：安装依赖后运行 python main.py，或双击“启动.bat”。
打包版：双击 YSP-Analyzer.exe。
首次启动会在 data/ 目录下创建数据库。

【自定义账号列表】
编辑“同类账号.txt”，格式：学校名称[TAB键]https://www.yspapp.cn/...
每行一个账号，保存后重新启动程序生效。


========================================
  界面中英对照
========================================

窗口标题：YSP · RADAR / 校园数据雷达

侧栏工作区：
  01 · COLLECT      采集中心
  02 · SNAPSHOTS    数据快照
  03 · EXPLORE      单次分析
  04 · COMPARE      对比分析
  05 · PULSE WATCH  爆款监测
  06 · SETTINGS     采集设置
  Theme             主题（切换浅色 / 切换深色）

─── 采集中心 / COLLECT ───────────────────────

  开始采集            创建新快照并采集账号数据
  暂停 / 继续         暂停或恢复当前任务
  停止                请求安全停止当前任务
  实时采集轨迹        青色节点表示已完成的账号队列
  运行记录            显示采集进度、失败账号与错误信息

顶部指标显示账号队列数量、最近采集时间、频率窗口和请求间隔。

─── 数据快照 / SNAPSHOTS ────────────────────

  快照                选择一次采集结果
  单位                切换“个 / 万 / 亿”显示
  搜索                按学校名称即时筛选
  管理快照            查看、重命名或删除快照
  导出 CSV            导出当前筛选后的表格

武汉科技大学默认以红色加粗显示。

─── 单次分析 / EXPLORE ──────────────────────

  快照                选择待分析的数据
  TOP                 排名显示数量，默认 15
  重点学校            在排名和图表中高亮的学校
  生成分析            计算概要并刷新排名预览
  粉丝排名 / 播放排名  打开交互柱状图
  粉丝分布            打开直方图
  粉丝 × 播放         打开散点图
  打开仪表盘          四类图表同屏查看

─── 对比分析 / COMPARE ──────────────────────

  基准快照            较早时间点
  对比快照            较晚时间点
  重点学校            对比完成后默认查看的学校
  开始对比            计算两个快照之间的变化
  学校检查器          搜索学校并查看粉丝、播放变化区间

程序会自动按时间先后纠正快照顺序。变化区间标为“仍在取整误差内”时，
说明当前差异可能来自央视频“万”单位的显示精度，不能确认真实增长。

─── 爆款监测 / PULSE WATCH ──────────────────

  起始 / 结束快照     选择监测日期区间，程序会纳入其间全部快照
  筛选门槛            用两侧减/加按钮调整；数值越小越容易发现线索，默认 3.0 倍
  扫描全部高校        同时分析账号列表中的全部高校
  爆发信号带          展示异常最强、最值得回看的高校与时间段
  全高校排名          比较播放增长、视频增长、单条效率、日均播放和数据覆盖率
  查看学校详情        选择或双击高校，打开该校的全部观察区间

程序先估算每所学校平时的单条视频播放波动，再用用户设置的倍数形成筛选门槛。
默认 3.0 倍表示只有明显超出常态的区间才进入疑似列表；调低会发现更多线索，
也可能增加误报。修改门槛后会立即重新筛选当前区间。程序使用真实间隔天数
计算日均播放；扣除“万/亿”显示取整误差；跨越缺失快照的区间不会被判为爆款。

学校详情窗口：
  播放增长脉冲        每两个相邻快照之间的累计播放增量
  新增视频节奏        同一区间内新增的视频数量
  单条新增视频效率    播放增量 ÷ 新增视频数，用于排除“只是发得多”
  疑似爆款            扣除“万/亿”取整误差后，单条效率仍高于 MAD 稳健阈值
  存量传播            没有新增视频但播放仍增长，说明旧内容继续传播
  数据回调            播放或视频数量下降，通常来自平台修正或采集口径变化

橙色区间只代表值得回看该时段发布内容，不能单凭累计数据确认具体哪条作品爆款。

─── 采集设置 / SETTINGS ─────────────────────

  请求间隔            单次请求之间的等待秒数，默认 3
  最大并发            同时请求数量，默认 3
  请求超时            单次请求超时秒数，默认 30
  最大重试            失败后的重试次数，默认 3
  频率窗口            频率保护统计天数，默认 7
  窗口内上限          频率窗口内允许的采集次数，默认 2
  保存设置            下一次采集时生效
  重置频率记录        仅清除频率计数，不删除快照

每个参数左侧为减号、右侧为加号；中间只输入数字，秒、天、次、任务数等单位固定
显示在独立区域，不能随数字一起编辑。按住减号或加号可连续调整。


========================================
  图表交互操作
========================================

  鼠标悬停柱图        高亮当前柱，并显示学校/区间名称与精确数值
  点击散点            标注账号名称
  滚轮滚动            放大或缩小图表
  底部工具栏          平移、框选缩放、复位和保存图片


========================================
  常见问题
========================================

Q: 双击程序没有反应？
A: 源码版请先运行 pip install -r requirements.txt；打包版请检查杀毒软件拦截。

Q: 采集失败或超时？
A: 检查网络；可在“采集设置”中适当增加“请求超时”和“最大重试”。

Q: 中文显示为方框？
A: 程序优先使用系统中文字体；请确认系统已安装微软雅黑、苹方或思源黑体。

Q: 数据保存在哪里？
A: 程序目录的 data/app.db（SQLite）。删除该文件会清除全部本地数据。

Q: 如何添加更多学校？
A: 编辑“同类账号.txt”，格式为学校名[TAB]URL，保存后重启程序。
